# CS-305-Software-Security
CS-305 Software Security Project 1

Artemis Financial is a consulting company that needed to protect sensitive financial data by securing its web application and fixing software vulnerabilities. To address their needs, I conducted a vulnerability assessment to find security risks like weak data protection, and then I added layers of security by configuring HTTPS with an SSL/TLS certificate and using SHA-256 algorithms to ensure data integrity. The most helpful part of the process was analyzing third-party libraries for known vulnerabilities, which taught me the value of proactive security practices like input validation and regular dependency checks. After refactoring the code, I ran static analysis tools and testing to verify that the application remained functional and that no new vulnerabilities were introduced. Ultimately, this assignment demonstrates my ability to implement secure coding standards and a defense-in-depth strategy, which are valuable technical skills I can confidently showcase to future employers.
